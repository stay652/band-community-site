# Band Community Site

밴드 커뮤니티 웹사이트 프로토타입입니다.

## 기술 스택
- Next.js 14
- React 18
- TypeScript

## 기능
- 닉네임 로그인
- 자유/공지 게시판
- 전체 일정 캘린더
- 실시간 채팅
- 자료실(등급별 접근)
- 관리자 패널
- 모바일 대응 UI

## 실행 방법
```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속하세요.
